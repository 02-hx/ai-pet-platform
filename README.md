# 它伴 TaBan - AI宠物社交平台

## 🎯 项目概述
它伴 TaBan 是一个基于 AI 技术的宠物情感社交平台，专注于为用户提供智能化的宠物陪伴体验。通过创建虚拟宠物分身，结合社交互动，构建"AI智能+情感连接+社区互动"的综合解决方案。

### 重要说明

本项目是可直接部署的静态网站原型。GitHub Pages 不提供数据库或服务器接口，因此用户资料、宠物分身、聊天记录、积分和健康档案仅保存在当前访客浏览器的 `localStorage` 中，不会在不同用户之间同步。

页面中的 AI 回复、主人私信、社区内容、投喂市场和系统状态均为前端演示逻辑。若要实现真实注册登录、多人实时社交、数据持久化、图片上传和 AI 接口，需要另外接入后端服务、数据库和经过保护的 API。

## 🚀 部署说明

### GitHub Pages
1. 将 `public-website` 文件夹中的所有文件上传到 GitHub 仓库根目录
2. 推送到 `main` 分支后，仓库内的 GitHub Actions 会自动发布 Pages
3. 访问：`https://02-hx.github.io/ai-pet-platform/`

### Netlify
1. 访问 https://app.netlify.com/drop
2. 拖拽 public-website 文件夹到网页
3. 等待部署完成
4. 获得访问地址

### Vercel
1. 访问 https://vercel.com/import
2. 选择 public-website 文件夹
3. 自动部署完成
4. 获得访问地址
